## Quickstart Recipes

### Run with z.ai (zero-config RPM throttling)

```bash
export ANTHROPIC_AUTH_TOKEN=<token>
export ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic
claude
```

### Run with DeepSeek-V4 (1M context, thinking mode)

```bash
export ANTHROPIC_AUTH_TOKEN=<deepseek key>
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-pro
claude
```

### Connect a Telegram bot

```bash
claude telegram setup           # interactive wizard
claude telegram start           # foreground
```

### Drive openclaude from Zed/Cursor (ACP)

```bash
# In Zed: point at the binary; it auto-launches with --acp
# Manual:
claude acp-link --host 127.0.0.1 --port 9315
```

### Spawn background session + dashboard

```bash
claude --bg                     # detach into tmux
claude agents                   # dashboard
# Or from inside a session: /bg  then  /agents
```

### Build code knowledge graph

```bash
# Inside REPL:
/graph build --full
/graph impact src/foo.ts
```

### Configure auto-fix loop

```jsonc
// .claude/settings.json
{
  "autoFix": {
    "enabled": true,
    "lint": "pnpm run lint",
    "test": "pnpm run test",
    "timeout": 120,
    "maxRetries": 3
  }
}
```
